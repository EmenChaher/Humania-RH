# Humania-RH — Human Resources Management Application

A full-featured desktop HR application built with Java 21 and JavaFX,
covering 6 interconnected business modules.

---

## 🚀 Modules

### User Management
- Role-based access (Admin, HR, Manager, Employee, Trainer)
- Multi-factor authentication (MFA) with QR codes (ZXing)
- Facial recognition login via OpenCV

### Recruitment
- Internal and external job postings
- Automated CV analysis
- AI-powered candidate-job matching (Groq)

### Skills & Training
- Competency matrix per employee
- Video-based training catalog (VLC4J)
- Learning progress tracking and individual development plans

### Leave & Absence
- Validation workflow for leave requests
- Team calendar (WebView)
- Balance tracking and automated email notifications

### Social Network
- Internal social feed with reactions, comments, and polls
- Real-time messaging (Supabase)
- Follow system and AI writing assistant (Groq)

### Coworking & Planning
- Interactive office map for space reservation
- Event and meeting management (CalendarFX)
- Employee onboarding and offboarding workflows

---

## 🛠 Tech Stack

**Core:** Java 21 · JavaFX · MySQL  
**AI:** Groq API · OpenCV  
**Real-Time:** Supabase  
**Libraries:** VLC4J · ZXing · CalendarFX · WebView  
**Architecture:** MVC · Singleton · Service/Repository
